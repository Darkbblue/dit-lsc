This folder contains the DiT variants we use for our work.
- DiT: Original DiT codebase, augmented with LSC designs.
- DiT-du: (du for down-up) Based on the original DiT codebase, we further add actual resolution changes to backbone architecture.
- SiT: Original SiT codebase, augmented with LSC designs. This is a case of $v$-prediction models.
- JiT: Original JiT codebase, augmented with JiT designs. This is a case of $x$-prediction models.
